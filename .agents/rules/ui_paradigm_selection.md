# UI Design Paradigm Consultation Rule

Kapag gagawa, magde-develop, o magre-redesign ng anumang User Interface (UI), website page, o UI component para sa user:

**Laging tanungin muna ang user kung anong specific UI style / paradigm ang nais nilang gamitin base sa listahan:**

1. **Skeuomorphism** — Realistic physical materials, metallic knobs, bevels, physical toggle switches, tactile textures.
2. **Neomorphism** — Soft extruded tactile plastic surfaces with dual highlights and drop shadows.
3. **Glassmorphism** — Frosted translucent acrylic blur (`backdrop-blur-md`), 1px luminous borders, deep multi-layer ambient glows.
4. **Claymorphism** — 3D inflated pillowy pastel containers with soft volumetric inner highlights and shadows.
5. **Minimalism** — Pure functional restraint, crisp monochrome typography, generous negative space, zero clutter.
6. **Maximalism** — High-energy kinetic neon gradients, dense cyber typography, intense vibrant visual density.
7. **Brutalism / Neo-Brutalism** — Heavy 3px-4px black borders, solid stark offset drop shadows, unapologetic raw geometric grid.
8. **Liquid Glass** — Fluid refractive dynamic wave distortion, iridescent chromatic dispersion.
9. **Bento Grid** — Modular asymmetric information architecture with micro-charts, telemetry cells, and metric cards.
10. **Spatial UI** — Apple VisionOS-style 3D floating z-depth elevation planes with interactive parallax.
